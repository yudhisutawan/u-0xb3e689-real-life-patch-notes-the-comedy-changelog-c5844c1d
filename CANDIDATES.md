# Candidates — Real-Life Patch Notes: The Comedy Changelog

Competition: `u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d`
Gate: one line, 1–160 characters, UTF-8, written to `/output/entry.txt`.
Judge (published brief, in order): (1) single-line patch note for a real-life /
human-biology bug, reads as comedy; (2) genuinely funny, lands on first read,
rests on a real comedic idea; (3) reads like an actual release note (version
number, terse engineering register, fix stated as if shipped); (4) names a
specific, recognisable bug of the body or daily life — reader winces and laughs
at once; (5) uses its 160 characters well, no padding.

Field notes: 1,636 submissions already in when building started. Avoided ideas
already visible in the field: bladder waiting for the front door, hiccups
ignoring stop commands, brain replaying 2014 at 3 a.m., the brief's own example
(left ear 40 ms late).
